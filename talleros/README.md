# TallerOS — Demo de gestión para talleres

Aplicación de demostración para pequeños talleres mecánicos. Incluye panel general, órdenes de reparación, agenda, clientes, inventario y presupuestos.

## Probarla
Abre `index.html` en el navegador o, si GitHub Pages está activado para este repositorio, visita:
https://andekarivera20-cpu.github.io/tradetools-business/talleros/

## Alcance de la demo
- Funciona solo en el navegador, con datos ficticios.
- Guarda los cambios en el almacenamiento local de cada navegador; los usuarios no comparten datos.
- No tiene inicio de sesión real ni base de datos remota.
- No debe usarse con datos reales de clientes o vehículos.

## Próximos pasos
Validar el interés de talleres antes de añadir autenticación, base de datos, permisos, copias de seguridad y puesta en producción.
